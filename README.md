# LinkedIn Opener Pro

A fast, free tool to bulk open LinkedIn profiles, find CEOs, and export leads — built with React, Vite, and Tailwind CSS.

## 🚀 Features

- **Bulk Profile Opening** — Paste company names, LinkedIn URLs, or websites and open all profiles instantly
- **CEO Finder** — Automatically searches and opens CEO profiles for each company
- **Export Leads** — Download a TSV spreadsheet with company names, websites, LinkedIn pages, and CEO profiles
- **Preview Panel** — Verify all links before opening

## 🛠️ Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- React Helmet Async (SEO)

## 📦 Getting Started

```sh
# Clone the repo
git clone <YOUR_GIT_URL>

# Navigate to project
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start dev server
npm run dev
```
